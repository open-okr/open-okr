An initiative and the key results it moves can now be linked and read from both sides. A key result's menu on Goals has View initiatives, which lists the initiatives that move it, and Add an initiative there arrives with that key result chosen. Add an initiative has an optional Key result it moves. The objective page lists each key result's initiatives, and a writer can unlink one, link one that exists, or start a new one for that key result; the drawer names them too. Every key result picker, the Board's included, now offers key results from every cycle being planned or running, quarterly and annual, with the running quarter first, rather than the current quarter only. An initiative's page names a linked key result from any cycle with its title and objective. A new read, `initiatives.keyResults`, lists the key results an initiative moves.
