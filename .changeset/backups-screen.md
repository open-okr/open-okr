Workspace admin has a Backups section. Take the workspace archive there (it moved from Import), see every archive anybody has taken of the workspace with who, when, the file and its rows, read how a copy is restored into a new workspace, and see where this server's own backups come from. No instance backup is shown or touched from a workspace screen, because each holds every workspace. A closed workspace's banner links here. The new read `workspace.listArchives` is in the API at full access.
