The copilot's answers show their formatting. Bold, italics, inline code, bullet and numbered lists, line breaks and code blocks are drawn as such, instead of the asterisks and dashes the model wrote, and a code block has its own Copy button once it is complete. A link or a web address in an answer stays plain text, because a model can repeat a link somebody planted in a passage, or invent one; the answer's sources are linked from what the search found. While an answer arrives, a marker that is not closed yet shows as typed until it is.
