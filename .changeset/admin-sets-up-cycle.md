An Admin can now set up and run a cycle: create it, name its sponsor and facilitator, book its planning sessions and set its publication deadline, write the annual frame, publish and close it. Before, only the workspace's Owner could. A Member and a Viewer still cannot, and archiving a cycle stays with the Owner. A new read, `cycles.setupAccess`, says whether the caller may.
