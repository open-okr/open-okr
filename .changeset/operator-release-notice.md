On a managed cloud, the operator console's Instance screen now has a Version card. It shows the running version and, when the update check is on and a newer release exists, links to that release and its upgrade notes. Customers are still not told, because the operator upgrades. `OPENOKR_UPDATE_CHECK` now switches the operator's check on a cloud, where it used to be ignored.
