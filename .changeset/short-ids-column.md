Every cycle, goal, key result, initiative, task, document and session now has a short identifier, the ten-character address KPIs already had. New ones get it when they are made, a moved workspace keeps its own unless the target already uses one, and data change 0034 gives one to everything made before the upgrade. Run it before upgrading to 0.8.0, which makes the identifier required.
