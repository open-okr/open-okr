The Agents and runs page now groups its cards under Run and review, The agents and History. The agents are a row of tabs that show each agent's state, schedule and write policy, with one agent's cards open at a time. The write policy is three tiles that are saved with a Save changes button (with Discard), and choosing Scoped direct still asks for confirmation. Each instruction stage is its own card with Save a new version, and the proposals, version history and recent runs lists scroll inside their cards. Running an agent, turning it off or on, applying or dismissing proposals, stopping a run and binding a scope still apply at once.
