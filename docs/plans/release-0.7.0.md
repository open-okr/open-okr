# Plan: release 0.7.0

Owner: Akmal. Written 8 November 2026, after the documentation accuracy review (pull request #189). Checked again against `main` at `7db8ab4c` on 9 November 2026.

Release 0.6.0 shipped on 8 November with the code as it stood after that review. Pull request #192 then fixed B4 and half of B8 for the 0.6.1 patch release, which is not cut yet. Release 0.7.0 carries the rest of what the review found:

1. **Bugs**: places where the code does not do what it plainly should. Section 1.
2. **Decisions**: four places where the code and METHOD.md disagree, and some stale text outside the documentation. Sections 2 and 3.
3. **Features the specification and design pages describe but the code does not have yet.** The review left those pages as they are, as the plan, and lists them here. Section 4.

Each row is one change in the CLAUDE.md change loop: one branch, one commit, one pull request. A row marked **design first** needs its design note written or updated, and approved with "design approved", before any code, because it touches security, access, tenant isolation, a new engine or the schema.

Sizes are rough: **S** is under a day, **M** is a few days, **L** is a week or more.
